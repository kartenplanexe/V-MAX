# Зависимости, лицензии и источники данных

Этот реестр относится к исходникам и Linux-поставке V-MAX. Он разделяет лицензии библиотек, уведомления в поставке и условия внешних сервисов. Собственная лицензия V-MAX этим файлом не назначается.

## Библиотеки и воспроизводимость

- [npm-инвентарь](third-party/npm-lock-inventory.json): все 230 записей `package-lock.json`, включая инструменты разработки и optional-пакеты других платформ. Для каждой есть версия, объявленная upstream лицензия, источник, integrity и признаки dev/optional. Это не число установленных пакетов рабочего контейнера.
- [Python/Linux-инвентарь](third-party/python-linux-runtime.json): девять установленных runtime-дистрибутивов из проверенного Linux-образа, Python 3.12.13, версии сверены с `planner/uv.lock`; перечислены сохранённые файлы лицензий и их SHA-256. Реестр не включает Debian и зависимости среды разработки.
- npm metadata: MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, BlueOak-1.0.0, 0BSD. MPL-2.0 относится к `lightningcss` и его платформенным пакетам в dev-части lockfile; исходники этих библиотек проект не изменяет. Официальное описание обязанностей: [Mozilla MPL FAQ](https://www.mozilla.org/en-US/MPL/2.0/FAQ/).
- Python runtime: OR-Tools и absl-py — Apache-2.0; immutabledict/six — MIT; protobuf — BSD-3-Clause; typing-extensions — PSF-2.0. pandas: BSD-3-Clause по сохранённому LICENSE. python-dateutil содержит Apache-2.0 для новых вкладов и BSD для прежних; сохраняется полный файл. NumPy объявляет `BSD-3-Clause AND 0BSD AND MIT AND Zlib AND CC0-1.0` и поставляет дополнительные уведомления о включённых компонентах; все license-файлы wheel остаются в контейнере.

В Docker npm-пакеты сохраняют собственные LICENSE/NOTICE/README, Python — dist-info с лицензиями, Debian — уведомления исходного базового образа. Лицензия скопированного Node.js находится в `/usr/local/share/doc/node/LICENSE`. Для uv 0.11.14 добавлен [upstream MIT-файл](third-party/licenses/uv-0.11.14-MIT.txt), полученный из [официального тега](https://github.com/astral-sh/uv/blob/0.11.14/LICENSE-MIT). Исчерпывающая проверка всех системных пакетов базового образа отдельно ещё не завершена.

[Уведомления браузерных библиотек](public/third-party-notices.txt) включаются в static-поставку по адресу `/third-party-notices.txt`. Генератор проходит runtime/peer-зависимости React, ReactDOM, MAX UI и MapGL wrapper и проверяет установленные версии по lockfile.

**Открытый upstream-пробел:** `@maxhub/max-ui@0.5.0` объявляет MIT в package.json, но отдельного LICENSE/copyright notice нет ни в npm-пакете, ни в корне tagged source `865fb899306191ca15a2074cd3bb9890a179d687`. Метаданные автора и лицензии сохранены; отсутствующий текст не сочинён. [Официальный исходник этой версии](https://github.com/max-messenger/max-ui/tree/865fb899306191ca15a2074cd3bb9890a179d687).

После изменения зависимостей:

```powershell
node scripts/dependency-inventory.mjs
node scripts/client-notices.mjs
```

CI выполняет обе команды с `--check`. Python-инвентарь обновляется скриптом `scripts/python-dependency-inventory.py` **в конечном Linux-образе**, с аргументом `/app/planner/uv.lock`; вывод сохраняется в `third-party/python-linux-runtime.json`. Инвентарь — доказательство конкретного состава, а не автоматическое разрешение любого способа использования.

## Внешние сервисы, данные и обозначения

| Компонент | Использование | Условия и граница подтверждения |
|---|---|---|
| MAX Bot API / Bridge / MAX UI | Бот, подписанный вход, mini-app и пользовательский выбор чата для передачи ссылки | [Официальная документация](https://dev.max.ru/docs). Лицензия UI не заменяет условия платформы и правила применения обозначений MAX. Логотипы в `public/` обозначают используемую платформу. |
| 2ГИС Places / Routing / MapGL | Категории, места, расписание, оценка переходов и карта при отдельном браузерном ключе | [Официальная документация API](https://docs.2gis.com/). BSD-2-Clause npm-wrapper не предоставляет права на картографический сервис, фотографии или каталог. Доступ ограничен действующими ключами и условиями их договора. Retention продукта 5 минут — техническая политика, а не самостоятельное разрешение 2ГИС. Production cache/фотографии/браузерный ключ требуют отдельного подтверждения. |
| KudaGo | Афиша и свежая проверка выбранного события/площадки | [API и открытая лицензия](https://docs.kudago.com/api/). Карточка содержит ссылку на конкретный источник; условия атрибуции сохраняются. Сервис не продаёт доступ к данным KudaGo и не подтверждает наличие билетов. Изображения событий пока не используются. |
| Yandex Cloud AI Studio | Необязательное структурирование текста в JSON | [Официальная документация](https://yandex.cloud/ru/docs/ai-studio/). Исходный текст и каталог выбранного региона передаются только для этого разбора; LLM не является источником маршрута и фактов о местах. Условия облачного аккаунта и обработки данных остаются применимыми. |
| Шрифты и иллюстрации | Системный стек шрифтов, собственные CSS/SVG элементы | Внешние веб-шрифты и фотобанки не подключены. Макеты Stitch являются референсом интерфейса; демонстрационные фото/цены не копируются в live-данные. |

Места, маршруты, ключи, MAX initData и личные сообщения не входят в этот реестр. Синтетические примеры отделены от внешних данных. Проверка Git/исходников на шаблоны секретов запускается через `npm run check:secrets`; она не заменяет проверку прав на данные.
